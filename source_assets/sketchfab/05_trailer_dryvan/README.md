# Truck Trailer FREE: raw source (not in Git)

- **Model:** "Truck Trailer FREE", https://sketchfab.com/3d-models/truck-trailer-free-575958a53e3d4e9f8bcfb1ee2cef67bf
- **Author:** NLM (Sketchfab `NLM-Group`).
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author.
- **Fetched:** 2026-11-11, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #221-#222).
- **This folder** holds Blender's export of the imported model (`05_trailer_dryvan.glb`, with its
  textures), not the original Sketchfab archive: the add-on deletes its download. Its top node
  carries the size and turn Claude Code set; the model stands on the ground, centred.
- **Size:** 2.39 x 13.73 x 4.33 m: scaled to 85% of the import, a 45 ft van. Its box is chunkier than a real one (no one scale matches a real trailer's width, length and height), so it is a compromise.
- **Contents:** 637,301 faces. Its textures are larger than the game needs and are to be
  reduced in its game files.
- **Branding:** None seen; plain white. The author's note says it "can be used in games".
- **Game files:** not made yet; the depot's build step makes slimmed copies.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
