# Semi Truck 1980: raw source (not in Git)

- **Model:** "Semi Truck 1980", https://sketchfab.com/3d-models/semi-truck-1980-5f6db10ac12645b8938a4b76942d9133
- **Author:** Brian Trepanier (Sketchfab `CMBC`).
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author.
- **Fetched:** 2026-11-11, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #221-#222).
- **This folder** holds Blender's export of the imported model (`04_tractor_1980.glb`, with its
  textures), not the original Sketchfab archive: the add-on deletes its download. Its top node
  carries the size and turn Claude Code set; the model stands on the ground, centred.
- **Size:** 2.55 x 8.47 x 3.91 m to the stack tops: turned square to the axes (it came turned 45 deg) and scaled to a 2.55 m body width, a long-nose sleeper tractor.
- **Contents:** 201,782 faces. Its textures are larger than the game needs and are to be
  reduced in its game files.
- **Branding:** None seen; blue paint and chrome. Check the grille for a badge when making the game files.
- **Game files:** not made yet; the depot's build step makes slimmed copies.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
