# PC Setup - Game Ready: raw source (not in Git)

- **Model:** "PC Setup - Game Ready", https://sketchfab.com/3d-models/pc-setup-game-ready-4126abfe9895488181dbde961e836788
- **Author:** Melon Polygons (Sketchfab `Melonpolygons`), published 2026-06-23.
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author ("THE
  GATEHOUSES").
- **Fetched:** 2026-11-20, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #348): the author asked for the
  guard booths' monitor, keyboard and kit to be real models; chosen from a labelled sheet.
- **This folder** holds Blender's export of the imported model, not the original Sketchfab
  archive (the add-on deletes its download): only its keyboard and mouse kept, cut from its one mesh by their loose parts and scaled together by the keyboard's width to 0.441 m (a compact full keyboard such as Logitech's MK270, 441 x 149 mm), each its own file (`keyboard`, 4,900 faces; `mouse`, 0.127 m long, 3,886 faces), its textures halved to 1024 pixels.
- **Branding:** A small maker's logo on the keyboard.
- **Game files:** `game/features/environments/industrial_loop/art/booth/models/` (keyboard, mouse), the
  same export.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
