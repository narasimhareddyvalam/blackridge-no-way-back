# Monitor Dell P2314H: raw source (not in Git)

- **Model:** "Monitor Dell P2314H", https://sketchfab.com/3d-models/monitor-dell-p2314h-c69f09bb812e46cdbd5bf6c62499b848
- **Author:** GregorJan (Sketchfab `login166`), published 2020-01-05.
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author ("THE
  GATEHOUSES").
- **Fetched:** 2026-11-20, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #348): the author asked for the
  guard booths' monitor, keyboard and kit to be real models; chosen from a labelled sheet.
- **This folder** holds Blender's export of the imported model, not the original Sketchfab
  archive (the add-on deletes its download): sized by its width to the real P2314H's 0.541 m (0.18 m deep, 0.43 m tall on its stand at its lowest), its screen facing glTF's front and named `Screen` (the game shows the guard's cameras on it), its base centred at the origin, its edge-only meshes dropped; 884 faces.
- **Branding:** Dell's logo on the bezel.
- **Game files:** `game/features/environments/industrial_loop/art/booth/models/` (dell_monitor), the
  same export.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
