# Industrial Overhead Door: raw source (not in Git)

- **Model:** "Industrial Overhead Door", https://sketchfab.com/3d-models/industrial-overhead-door-20ced63367824ec1a2ada0fbf118b413
- **Author:** Maxwell autodoors (Sketchfab `maihupronoob`).
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author.
- **Fetched:** 2026-11-11, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #221-#222).
- **This folder** holds Blender's export of the imported model (`01_door_maxwell.glb`, with its
  textures), not the original Sketchfab archive: the add-on deletes its download. Its top node
  carries the size and turn Claude Code set; the model stands on the ground, centred.
- **Size:** 6.00 x 0.38 x 3.34 m with its red wall panel; the door itself 2.64 x 2.82 m at this scale (2.44 x 2.60 m, 8 x 8.5 ft, at the source's own scale), with three vision windows.
- **Contents:** 201,419 faces. Its textures are larger than the game needs and are to be
  reduced in its game files.
- **Branding:** None seen. The red wall panel round the door is not used in the game.
- **Game files:** not made yet; the depot's build step makes slimmed copies.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
