# CONTAINER LOADER: raw source (not in Git)

- **Author:** jinjinjin (Sketchfab `thejinjinjin`), published 2022-05-18.
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author ("THE
  CONTAINER YARD").
- **Fetched:** 2026-11-20, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #351), after the first choice,
  "KALMAR DRU450", proved to be only a spreader.
- **This folder** holds Blender's export, not the original archive: imported at 12 m tall (its
  tyres 1.87 m across and its track 4.05 m, an empty-container handler's), its spreader drawn in
  from 11.2 m to 6.06 m (20 ft) by sliding its arms' ends inward as its telescoping arms do, set
  on the ground and centred; its textures halved to 1024 pixels; 26,446 faces.
- **Branding:** "TMN HEAVY INDUSTRY" on its spreader (fictional).
- **Game files:** `game/features/environments/industrial_loop/art/container_yard/top_loader/`.
