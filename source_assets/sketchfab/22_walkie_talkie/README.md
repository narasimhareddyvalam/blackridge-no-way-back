# Walkie Talkie: raw source (not in Git)

- **Model:** "Walkie Talkie", https://sketchfab.com/3d-models/walkie-talkie-5d57f97915a844f584157cb86a474eba
- **Author:** barism09 (Sketchfab `barism09`), published 2022-05-06.
- **Licence:** CC BY 4.0 (Sketchfab's "CC Attribution"). The game credits the author ("THE
  GATEHOUSES").
- **Fetched:** 2026-11-20, through the Blender MCP add-on's Sketchfab import, by Claude Code at
  the author's request (`docs/AUTHOR_PROMPTS_AND_DECISIONS.md` #348): the author asked for the
  guard booths' monitor, keyboard and kit to be real models; chosen from a labelled sheet.
- **This folder** holds Blender's export of the imported model, not the original Sketchfab
  archive (the add-on deletes its download): sized to 0.17 m tall with its aerial (a handheld PMR radio), its face toward glTF's front, standing on the origin; 6,800 faces.
- **Branding:** Kenwood's name on its face.
- **Game files:** `game/features/environments/industrial_loop/art/booth/models/` (walkie_talkie), the
  same export.
- **Git:** `.gitignore` keeps these files out of Git; only this README is tracked.
