# Foggy windshield texture credits

All three images are original. Claude Code wrote
`tools/make_fog_textures.py` on 2026-10-29, and the images were generated by
running it (`python3 tools/make_fog_textures.py`, fixed seed 20261029). No
generative model, photograph or third-party asset was used, so no licence
applies.

| File | Size | Meaning | Shader reads it as |
| --- | --- | --- | --- |
| `fog_color.png` | 1024 × 1024 RGB | Soft grey-white fog colour, about (222, 228, 233) with small cool/warm variation; sRGB | Colour (`source_color`) |
| `fog_data.png` | 1024 × 1024 RGB | Fog thickness in red: 0 = clear, 1 = thick. Stored as grey, so green and blue copy red and are unused | Data (no colour hint) |
| `fog_normal.png` | 1024 × 1024 RGB | Tangent-space normals from a droplet height field, **OpenGL convention (green up)**; flat is about (128, 128, 255) | Data (`hint_normal`) |

All three tile seamlessly. The curl ratio of `fog_normal.png` is 0.0033 read
as GL and 1.9967 read as DX. That means a real surface sits behind it, in the
OpenGL convention. The known-good Poly Haven pair gives 0.58 / 1.42; see
`game/tests/calibration/ATTRIBUTION.md`.

Import settings are set explicitly in each `.import` file: `compress/mode=0`
(Lossless), `mipmaps/generate=true`, `detect_3d/compress_to=0`, and
`compress/normal_map=1` (Enable) for `fog_normal.png` or `2` (Disable) for the
other two.
