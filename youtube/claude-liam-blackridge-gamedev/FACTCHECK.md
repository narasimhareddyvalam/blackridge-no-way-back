Algebra for B06: mix(C, C·n·b, a) = C(1 − a) + C·n·b·a = C(1 − a + a·n·b), exact.

Worked case, hub red at a = 0.5, n = 1.0, b = 0.55: 1 − 0.5 + 0.5 × 1.0 × 0.55 = 0.775, so
135 × 0.775 = 104.625 ≈ 105. The capture reads 105.

The other channels check too:
- green: 156 × (0.5 + 0.5 × 0.55 × 0.55) = 156 × 0.65125 = 101.6 ≈ 102;
- blue: 148 × (0.5 + 0.5 × 0.20 × 0.55) = 148 × 0.555 = 82.1 ≈ 82.

## Hint experiment

| Claim | Source | Check |
| --- | --- | --- |
| Three grey bands 64/128/192 read through two samplers, switched by `show_data` | `hint_experiment.gdshader:5,6,9,15`; `tools/make_hint_png.gd` | Yes. |
| Predicted 64/128/192 as colour, 137/188/225 as data | CHANGE-BRIEF §4.1 | See the encode algebra below. |
| Forward+ matched; Compatibility showed the file values on both quads | `evidence/captures/hint_*`; TEST-REPORT hint table | The 4K captures are re-checked in `capture/hint_samples_4k.txt`. |

Encode for B19: encode(x) = 1.055·x^(1/2.4) − 0.055 for x > 0.0031308, otherwise 12.92·x.

- 64/255 = 0.25098. Then 0.25098^(1/2.4) = e^(−1.38238/2.4) = e^(−0.57599) = 0.56216.
  Next, 1.055 × 0.56216 − 0.055 = 0.53808, and × 255 = 137.2 ≈ 137.
- 128 gives 0.73665 × 255 = 187.8 ≈ 188.
- 192 gives 0.88235 × 255 = 225.0.

Correction: the first script draft said 0.537. The computed value is 0.538, and the narration
uses 0.538.
